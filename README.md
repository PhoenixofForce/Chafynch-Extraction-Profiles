# Chafynch Extraction Profiles

This repository contains ready-to-use profiles for some common tea stores. Just copy the JSON into your [Chafynch](https://github.com/PhoenixofForce/Chafynch) instance under `Settings > Extraction Profiles`.

I respected the `robots.txt` and only included shops where it was allowed to scrape the products.
> If you are a shop owner and want your config gone, create an issue, send me a mail or a dm.
